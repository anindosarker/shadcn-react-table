<Steps>

<Step>

### Initialize shadcn/ui

Skip this if the project already uses shadcn/ui on the Radix base. The table needs the Radix base, Tailwind CSS v4 and React 18 or newer; Base UI and React Aria are not supported in this version.

<InitCommand />

</Step>

<Step>

### Add shadcn-table

Copies the table source into `components/ui/shadcn-table/` and installs the shadcn/ui parts and npm packages it needs. Run it again with `--overwrite` to update.

<InstallCommand />

</Step>

<Step>

### Import

```tsx
import {
  ShadcnTable,
  useShadcnTable,
} from '@/components/ui/shadcn-table';
```

Columns, data and the hook: [Usage](/docs/getting-started/usage). Letting an agent do all of this: [AI Agent Setup](/docs/getting-started/agents).

</Step>

</Steps>
