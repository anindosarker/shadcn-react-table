### Ask your agent

<AgentPrompt />

The prompt points the agent at [`/SKILL.md`](/SKILL.md): install, the usage rules, where the option references are, and how to pull any docs example into the project. Every example page also has a "Copy prompt" in its menu for that example.

### Skill

The same file installs as a skill, so the agent knows the table before you ask:

```bash
npx skills add anindosarker/shadcn-table
```

### Docs as markdown

- [`/llms.txt`](/llms.txt): index of all pages
- [`/llms-full.txt`](/llms-full.txt): all pages in one file
- Any page: its path under `/llms.mdx/docs` plus `/content.md`, for example [`/llms.mdx/docs/api/table-options/content.md`](/llms.mdx/docs/api/table-options/content.md). "Copy page" in the page bar copies the same text.

### Project rules

For `CLAUDE.md` or `AGENTS.md` when the skill is not installed:

```md
## shadcn-table

- Data table: components/ui/shadcn-table (from the shadcn registry, edit freely).
- Before changing table options read /llms.mdx/docs/api/table-options/content.md
  on the docs site. Column options: /llms.mdx/docs/api/column-options/content.md.
- `data` and `columns` given to useShadcnTable must be stable
  (useMemo, useState or module scope).
- Reinstall: pnpm dlx shadcn@latest add anindosarker/shadcn-table/shadcn-table --overwrite
  (replaces local edits in that directory).
```
