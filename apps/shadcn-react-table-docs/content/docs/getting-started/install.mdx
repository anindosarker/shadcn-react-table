shadcn-react-table is a shadcn registry item. One command copies the table source into your project and installs what it needs. You own the files.

### Requirements

- A shadcn/ui project on the **Radix** base with Tailwind CSS v4. No shadcn/ui yet: `pnpm dlx shadcn@latest init --base radix`
- React 18 or newer

Base UI and React Aria are not supported in this version.

### What gets installed

- `components/ui/shadcn-react-table/` the table source. Edit anything.
- The shadcn/ui parts the table uses, added to `components/ui/` when missing: alert, badge, button, collapsible, combobox, dialog, dropdown-menu, field, input, input-group, label, native-select, pagination, popover, progress, radio-group, select, separator, skeleton, slider, spinner, switch, tooltip.
- npm dependencies: `@tanstack/react-table`, `@tanstack/react-virtual`, `@tanstack/match-sorter-utils`, `highlight-words`, `class-variance-authority`, `lucide-react`, `radix-ui`.
- A few keyframes appended to your global stylesheet.

### First table

```tsx
import { ShadcnReactTable } from '@/components/ui/shadcn-react-table';

const columns = [
  { accessorKey: 'name', header: 'Name' },
  { accessorKey: 'age', header: 'Age' },
];
const data = [
  { name: 'Ada', age: 36 },
  { name: 'Linus', age: 54 },
];

export default function App() {
  return <ShadcnReactTable columns={columns} data={data} />;
}
```

Columns, data and the hook form: [Usage](/docs/getting-started/usage).

### Locales

English ships with the table. Every other language is its own item:

```tsx
import { SRT_Localization_DE } from '@/components/ui/shadcn-react-table/locales/de';
```

Available codes and custom translations: [Localization](/docs/guides/localization).

### Updating

Run the install command again with `--overwrite`. Files under `components/ui/shadcn-react-table/` are replaced, including your edits.

### Common errors

```bash
Uncaught TypeError: (0 , import_react15.useId) is not a function
    at useSRT_TableOptions (useSRT_TableOptions.ts:95:8)
```

React is older than 18. Upgrade `react` and `react-dom`.

```bash
Error: Element type is invalid: expected a string (for built-in components)
or a class/function (for composite components) but got: undefined.
```

`ShadcnReactTable` is a named export:

```diff
- import ShadcnReactTable from '@/components/ui/shadcn-react-table'
+ import { ShadcnReactTable } from '@/components/ui/shadcn-react-table'
```
