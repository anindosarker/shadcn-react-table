These are install instructions for the latest version of Shadcn React Table (V1)

### Compatibility

First, before installing Shadcn React Table, let's make sure you have the correct versions of React, TanStack Table, Tailwind CSS, and shadcn/ui installed.

<CompatibilityTable />

> `shadcn-react-table` is distributed through the shadcn registry: the install command below copies the component into your project and installs its dependencies.
>
> If you are already using shadcn/ui, you probably already have most of these peer dependencies installed.
>
> Just double-check that you have the following in your project, or use the [full install commands](<#install-with-required-peer-dependencies-(recommended)>) below.
>
> 1.  A shadcn/ui project initialised with `shadcn init` (Tailwind CSS v4)
> 2.  `react` and `react-dom` (v18+)
>
> The install command adds `@tanstack/react-table` (v8), `@tanstack/react-virtual`, `lucide-react` and the shadcn/ui components the table is built from.

### Quick Install

```bash
pnpm dlx shadcn@latest add anindosarker/shadcn-react-table/shadcn-react-table
```

### Install With Required Peer Dependencies (Recommended)

```bash
pnpm dlx shadcn@latest add anindosarker/shadcn-react-table/shadcn-react-table
```

> You do NOT need to install `@tanstack/react-table`, as it is already an internal dependency of `shadcn-react-table`, and must use an exact version already specified internally.
>
> All internal dependencies: `@tanstack/match-sorter-utils`, `@tanstack/react-table`, `@tanstack/react-virtual`, and `highlight-words`

### Common Errors

If you see a react import error like this:

```bash
Uncaught TypeError: (0 , import_react15.useId) is not a function
    at useSRT_TableOptions (useSRT_TableOptions.ts:95:8)
    at useShadcnReactTable (useShadcnReactTable.ts:12:24)
```

It means that you don't have the correct version of React installed. Make sure you have React 18.0 or higher.

---

If you get an error like this:

```bash
"Error: Element type is invalid: expected a string (for built-in components)
or a class/function (for composite components) but got: undefined.
```

You likely forgot to export your component from the file it's defined in,
or you might have mixed up default and named imports.

Or You might be trying to import `ShadcnReactTable` from the default export still, which is not supported. Make sure you are importing the named export instead:

```diff
- import ShadcnReactTable from '@/components/ui/shadcn-react-table'
+ import { ShadcnReactTable } from '@/components/ui/shadcn-react-table'
```

Or your shadcn/ui components may be out of date. Re-run the install command above to update the component and its registry dependencies.

---

If you are using an older version of `webpack` or `create-react-app` and get an error like this:

```bash
./node_modules/@tanstack/virtual-core/build/lib/index.esm.js 147:92
Module parse failed: Unexpected token (147:92)
File was processed with these loaders:
```

Then try upgrading either `webpack` or `react-scripts` to the latest versions.
