## Basic Example

Shadcn React Table enables client-side sorting, filtering, search, pagination, column hiding, and more by default. These features can easily be disabled or customized further, but here is a showcase of their default behavior. Be sure to check out a more [Advanced Example](/docs/examples/advanced) to see how more features can be customized.
