## Chart Detail Panel Example

The detail panel features can be used for a variety of purposes. In this example, we are integrating the new [Recharts](https://recharts.org/) library to display an expandable line chart for each row.

You could, of course, use any charting library that you prefer, but using Recharts will give you a consistent look and feel with Shadcn React Table and any other shadcn/ui components you may be using.
