Shadcn React Table has full support for localization (i18n). Some locales are included by default, but if your language is not yet supported, you can still easily add your own custom translations to the `localization` table option.

### Built-in Locales

English ships with the table. Every other locale is its own registry item, `shadcn-react-table-locale-<code>`, installed with the same command as the table:

```bash
pnpm dlx shadcn@latest add anindosarker/shadcn-react-table/shadcn-react-table-locale-de
```

The item lands in `components/ui/shadcn-react-table/locales/<code>.ts` and is imported from `'@/components/ui/shadcn-react-table/locales/<code>'`. Available codes:

`ar`, `az`, `bg`, `cs`, `da`, `de`, `el`, `en`, `es`, `et`, `fa`, `fi`, `fr`, `he`, `hr`, `hu`, `hy`, `id`, `it`, `ja`, `ko`, `nl`, `no`, `np`, `pl`, `pt`, `pt-BR`, `ro`, `ru`, `sk`, `sr-Cyrl-RS`, `sr-Latn-RS`, `sv`, `tr`, `uk`, `vi`, `zh-Hans`, `zh-Hant`

> If your language is not yet supported, please consider making a PR to add it to the library! See [here on GitHub](https://github.com/anindosarker/shadcn-react-table/tree/master/packages/shadcn-react-table/src/components/ui/shadcn-react-table/locales).

### Custom Non-Built-In Translations

If you want to use a language that is not included in the library, you can still easily add your own custom translations to the `localization` table option.

```jsx
const table = useShadcnReactTable({
  columns,
  data,
  localization: {
    language: 'pt', // BCP 47 language tag for number formatting
    actions: 'Ações',
    and: 'e',
    cancel: 'Cancelar',
    changeFilterMode: 'Alterar o modo de filtro',
    changeSearchMode: 'Alterar o modo de pesquisa',
    clearFilter: 'Limpar filtros',
    clearSearch: 'Limpar pesquisa',
    clearSort: 'Limpar classificações',
    clickToCopy: 'Clique para copiar',
    // ... and many more - see link below for full list of translation keys
  },
});

return <ShadcnReactTable table={table} />;
```

For a full list of all available translation keys, see [here](https://github.com/anindosarker/shadcn-react-table/blob/master/packages/shadcn-react-table/src/components/ui/shadcn-react-table/locales/en.ts).
Please note that each localization object should include a `language` property containing a valid BCP 47 language tag to ensure proper number formatting.

If you end up fully translating SRT into another language that is not yet supported, please consider making a PR to add it to the library so that everyone can use it!
