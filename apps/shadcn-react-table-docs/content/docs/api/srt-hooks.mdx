<br />

SRT has been adopting more and more of a hooks based approach for its internal logic. Its API is becoming more standardized so that you can use the same hooks that the SRT components use internally to build your own custom headless table if you want to.

### useShadcnReactTable

[Source Code](https://github.com/anindosarker/shadcn-react-table/blob/main/packages/shadcn-react-table/src/components/ui/shadcn-react-table/hooks/useShadcnReactTable.ts)

> This is probably the only SRT hook you will need to use, unless you are writing a custom headless table.

This is the main hook from Shadcn React Table. It creates a TanStack Table instance with all of the features that SRT provides and that you enable, and uses the proper default table options.

```tsx
import { useShadcnReactTable } from '@/components/ui/shadcn-react-table';

const table = useShadcnReactTable({
  ...options,
});
```

This hook is the combination of 2 other internal SRT hooks: [`useSRT_TableOptions`](#usesrt_tableoptions), and [`useSRT_TableInstance`](#usesrt_tableinstance).

### useSRT_TableOptions

[Source Code](https://github.com/anindosarker/shadcn-react-table/blob/main/packages/shadcn-react-table/src/components/ui/shadcn-react-table/hooks/useSRT_TableOptions.ts)

This hook simply takes in your custom table options and merges them with the default table options. It also does some extra logic to make sure that some default table options are set correctly based on other enabled features. For example, if you enable row virtualization features, the sticky header will also be enabled by default, and the layoutMode will adjust accordingly.

```tsx
import { useSRT_TableOptions } from '@/components/ui/shadcn-react-table';

const transformedTableOptions = useSRT_TableOptions({
  ...options,
});
```

### useSRT_TableInstance

[Source Code](https://github.com/anindosarker/shadcn-react-table/blob/main/packages/shadcn-react-table/src/components/ui/shadcn-react-table/hooks/useSRT_TableInstance.ts)

This is where most of the magic happens. This hook is responsible for creating the TanStack Table instance, and adding all of the SRT features to it. It needs table options to be passed in to it correctly, with good defaults, and it will return the table instance.

```tsx
import { useSRT_TableInstance } from '@/components/ui/shadcn-react-table';

const table = useSRT_TableInstance({
  ...transformedTableOptions, //usually from useSRT_TableOptions
});
```

This hook also uses the [`useSRT_Effects`](#usesrt_effects)

### useSRT_Effects

[Source Code](https://github.com/anindosarker/shadcn-react-table/blob/main/packages/shadcn-react-table/src/components/ui/shadcn-react-table/hooks/useSRT_Effects.ts)

This hook is responsible for adding some extra useEffect hooks to the table instance. These hooks are needed by some SRT features on a table wide level.

### useSRT_Rows

[Source Code](https://github.com/anindosarker/shadcn-react-table/blob/main/packages/shadcn-react-table/src/components/ui/shadcn-react-table/hooks/useSRT_Rows.ts)

This hook is mostly a wrapper around `table.getRowModel`, but with a bit more custom logic for fuzzy ranking, row pinning, and more. It consumes a `table` instance and returns the rows that should be rendered in the main table body. This can be a useful hook if you are writing a custom headless table, but still want all of the extra SRT enhanced behavior for fuzzy ranking, row pinning, etc. Alternatively, you can just use `table.getRowModel()` for a more vanilla TanStack Table experience.

```tsx
import {
  useShadcnReactTable,
  useSRT_Rows,
} from '@/components/ui/shadcn-react-table';

const table = useShadcnReactTable({
  ...options,
});

const rows = useSRT_Rows(table);

return rows.map((row) => {
  //render row
});
```

### useSRT_ColumnVirtualizer

[Source Code](https://github.com/anindosarker/shadcn-react-table/blob/main/packages/shadcn-react-table/src/components/ui/shadcn-react-table/hooks/useSRT_ColumnVirtualizer.ts)

This hook is a wrapper around the `useVirtualizer` hook from TanStack Virtual. It consumes a `table` instance and returns a Column Virtualizer instance that is optimized for SRT table columns, with considerations for other SRT features like column pinning, column resizing, column hiding, and more.

```tsx
import {
  useShadcnReactTable,
  useSRT_ColumnVirtualizer,
} from '@/components/ui/shadcn-react-table';

const table = useShadcnReactTable({
  ...options,
});

const columnVirtualizer = useSRT_ColumnVirtualizer(table);
```

You would only need to use this hook if you are writing a custom headless table and want the same default column virtualization behavior that SRT provides. If you are using the SRT components, this hook is already used internally by the `SRT_Table` component.

### useSRT_RowVirtualizer

[Source Code](https://github.com/anindosarker/shadcn-react-table/blob/main/packages/shadcn-react-table/src/components/ui/shadcn-react-table/hooks/useSRT_RowVirtualizer.ts)

This hook is a wrapper around the `useVirtualizer` hook from TanStack Virtual. It consumes a `table` instance and returns a Row Virtualizer instance that is optimized for SRT table rows, with considerations for other SRT features like row pinning, row dragging, and more.

```tsx
import {
  useShadcnReactTable,
  useSRT_RowVirtualizer,
} from '@/components/ui/shadcn-react-table';

const table = useShadcnReactTable({
  ...options,
});

const rowVirtualizer = useSRT_RowVirtualizer(table);
```

You would only need to use this hook if you are writing a custom headless table and want the same default row virtualization behavior that SRT provides. If you are using the SRT components, this hook is already used internally by the `SRT_Table` component.
