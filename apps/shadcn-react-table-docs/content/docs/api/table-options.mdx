> Many of the options you can pass to `useShadcnReactTable` are the same as the ones you can pass to the TanStack Table [useReactTable](https://tanstack.com/table/v8/docs/api/core/table) hook.

Here is a list of all the table options that you can pass to the `useShadcnReactTable` hook.

```jsx
const table = useShadcnReactTable({
  // all the options that you can pass here (recommended)
});

//or all of the props that could be passed to `<ShadcnReactTable />` IF not using `useShadcnReactTable` hook
return (
  <ShadcnReactTable
  // all of the props that could be passed here if no `table` prop is passed
  />
);

return <ShadcnReactTable table={table} />; //recommended
```
