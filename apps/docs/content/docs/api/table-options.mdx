> Many of the options you can pass to `useShadcnTable` are the same as the ones you can pass to the TanStack Table [useReactTable](https://tanstack.com/table/v8/docs/api/core/table) hook.

Here is a list of all the table options that you can pass to the `useShadcnTable` hook.

```jsx
const table = useShadcnTable({
  // all the options that you can pass here (recommended)
});

//or all of the props that could be passed to `<ShadcnTable />` IF not using `useShadcnTable` hook
return (
  <ShadcnTable
  // all of the props that could be passed here if no `table` prop is passed
  />
);

return <ShadcnTable table={table} />; //recommended
```
